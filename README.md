# MetaJetCore

Метаоркестратор Claude Code внутри JetBrains IDE.

Одна сессия Claude Code — оркестратор — открывает рядом с собой вкладки с другими
**полноценными** сессиями Claude Code (имплементер, ресерчер, ревьювер), раздаёт им задачи,
отвечает на их вопросы вместо разработчика и сводит результат. Разработчик читает и пишет
только в одну вкладку.

Субагенты не используются: каждый агент — отдельный процесс со своим контекстом, который
сохраняется между итерациями. Именно это делает схему дешевле субагентов, которые при каждом
запуске ресерчат заново то, что уже было выяснено.

```
┌─ IDE ───────────────────────────────────────────────┐
│  mjc-orc  (ты пишешь сюда)  │  mjc-impl-be          │
│         │ MCP               │  mjc-rsrch            │
│         ▼                   │                       │
│   MetaJetCore plugin ───────┘  открывает вкладки    │
└─────────────────────────────────────────────────────┘
       mjc-orc ⇄ mjc-impl-be — штатный cross-session messaging
```

## Развернуть с нуля

Нужно: JetBrains IDE 2025.1+, Claude Code 2.1.234+, JDK 21 (или Gradle сам его скачает).

```bash
# 1. Собрать плагин
cd plugin
./gradlew buildPlugin          # zip окажется в plugin/build/distributions/

# 2. Установить
#    Settings | Plugins | ⚙ | Install Plugin from Disk… → выбрать этот zip
#    Перезапустить IDE

# 3. Подключить оркестратор к плагину
#    Tools | MetaJetCore | Copy MCP Config Command
#    вставить полученную команду в терминал (это claude mcp add --transport http …)

# 4. Проверить, что всё нашлось
#    Tools | MetaJetCore | Diagnostics
```

Wrapper Gradle в репозитории нет — сгенерировать один раз:

```bash
cd plugin && gradle wrapper --gradle-version 8.10.2
```

либо открыть `plugin/` в IntelliJ IDEA, она предложит сама.

### Настройка под свою команду запуска

Если `claude` вызывается через обёртку, укажите её в
`Settings | Tools | MetaJetCore | Команда запуска`.

Проверьте, пробрасывает ли обёртка аргументы — от этого зависит, будет ли у ролей жёсткое
ограничение набора инструментов:

```bash
MJC_LAUNCH=<ваша-обёртка> ./scripts/check-wrapper.sh
```

Не пробрасывает — почините одной строкой (`exec claude "$@"`) либо переключите
`Передача роли` на `Message` в настройках плагина.

## Использование

В любой сессии Claude Code вызовите `/orchestrate` — сессия становится оркестратором.
Скилл ставится плагином в `~/.claude/skills/orchestrate/` автоматически, поэтому доступен
во всех проектах.

Дальше разговаривайте только с оркестратором: он сам заведёт нужных агентов.

## Работа без плагина

Всё работает и руками, плагин нужен только для автоматического открытия вкладок:

```bash
./scripts/spawn-agent.sh implementer mjc-impl-be
```

## Перенос в другой проект

С установленным плагином — **переносить нечего**. Роль оркестратора живёт в пользовательском
скоупе, роли агентов плагин подставляет инлайном. В целевом проекте нужны только два ключа:

```json
{ "crossSessionInbound": "accept", "permissions": { "defaultMode": "auto" } }
```

Подробности и подводные камни — `docs/ARCHITECTURE.md` §12.
